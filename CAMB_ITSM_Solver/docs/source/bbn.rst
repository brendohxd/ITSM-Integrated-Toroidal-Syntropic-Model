BBN models
==================================

Bundled interpolation tables may spell the baryon-density axis as either
``ombh2`` or ``Ombh2``. The table adapter prefers an exact header match and
accepts one unique case-insensitive match; missing, ambiguous or malformed
schemas fail closed. This is a table-schema compatibility rule, not an
additional physical transformation. The BBN-001 repository control documents
the bounded table and CAMB-bridge checks separately from any ITSM cosmology
claim.
