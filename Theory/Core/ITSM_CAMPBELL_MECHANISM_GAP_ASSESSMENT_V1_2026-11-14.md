## Smallest supported follow-through

First execute A16.1: identify observable channels and separate changes in
sector bookkeeping from changes in predicted total stress and matter response.
In parallel prepare an A16.2 paired-state closure test using an existing
same-action linear control, without adopting a new bath or adding a wake field.

1. Freeze retained observables (including rates required to define their state),
   hidden variables, actual constraints, global charges and the declared domain.
2. Establish whether two allowed initial perturbations can agree in all retained
   state variables yet differ in hidden data. Check physical non-gauge difference.
3. Reuse a verified propagator only if it covers those seeds. Otherwise derive
   the necessary extension and error bound before claiming a numerical result.
4. Compare later retained responses above the certified numerical error. Retain
   full dynamics; no continual projection or altered diagnostic thresholds.
5. Distinguish a sufficient instantaneous state, demonstrated missing retained
   variables/history dependence, and a missing-domain/input outcome.
6. A memory kernel/hidden-state forcing map is a subsequent calculation, not
   furnished by finding a difference. A statistical noise law additionally
   needs an ensemble. A decoupled or short-memory control must be an actual
   permitted limit of the same declared system, not an edited coupling matrix.

For the broader organizing hypothesis, separately test correlations, available
work, persistence and tensor stress under declared drive/state conditions.
No equal entropy cancellation is imposed. No memory closure can erase a
demonstrated pathology of its parent or identify free MAT coefficients by itself.
