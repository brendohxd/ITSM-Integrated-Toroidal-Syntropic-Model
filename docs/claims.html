Claim hygiene

The recovery programme treats intellectual honesty as load-bearing. Status labels and buckets keep identity open without re-inflating failed packaging.

Status of every claim

Exactly one label

LabelMeaning
Derived Checked calculation from declared assumptions in a stated domain
Conditional Requires a named postulate, matching hypothesis, or restricted limit
Open Defined calculation or test incomplete — default for untested routes
Rejected Stated derivation form failed; may return only with a new gate and new math — not by slogan

Three buckets

Not Derived ≠ hard ban

A — Hard ban

Proven false packaging, fabrication, or governance failure. Never as live Derived.

e.g. circulation quantizes \(a_0\); free-field 13/12 attractor as prediction; lunar SWNT as proof

B — Packaging dead

Old closed form failed; the physical question may return under a new gate.

e.g. scale \(a_0\sim cH_0\) as phenomenology; driven CBR-002 anisotropy

C — Reassess

Sidelined for the wrong reason; active Conditional/Open identity routes.

e.g. AQUAL-class IR; syntropy; wake; SWNT principle

Open-options rule

Do not over-lock the programme

May do anytime

  • Formalize identity pillars as Conditional/Open
  • Work parallel TOP / VOR / WAK / \(Q_{\mathrm{syn}}\)
  • When a core gate stalls, dig harder among pillars (including winding principle)
  • Use AQUAL-class IR as Conditional baseline for honest fits

Must not do

  • Treat untested routes as hard-banned because recovery has not run them
  • Treat UVIR-only as the only allowed research
  • Force any one pillar (incl. SWNT) if math shows it is unused or wrong
  • Re-publish old slogans as Derived
