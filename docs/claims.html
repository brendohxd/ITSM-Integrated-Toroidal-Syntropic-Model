Claim hygiene

The ITSM programme enforces fail-closed claim discipline: no claim is promoted beyond its verified gate status.

Status Definitions

Exactly one label per scientific claim

LabelMeaning
Derived Checked calculation from declared assumptions in a stated domain
Conditional Requires a named postulate, matching hypothesis, or restricted limit
Open Defined calculation or test incomplete — default for untested routes
Rejected / Quarantined Stated derivation form failed or quarantined for code-to-claim violations
