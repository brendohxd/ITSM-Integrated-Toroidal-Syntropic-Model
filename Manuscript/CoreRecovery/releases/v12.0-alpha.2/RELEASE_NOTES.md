# ITSM Core 12.0-alpha.2

Release date: 2026-07-26

This release freezes the manuscript after:

- correcting the frame-sector speed normalization;
- completing the scalar ADM-readiness and background-completion screens;
- deriving the FRW minisuperspace equations; and
- verifying a representative homogeneous, isotropic, on-shell expanding
  branch.

The scalar perturbation ADM reduction remains open. The background-existence
result does not establish perturbative stability, full cosmological viability,
or observational acceptance.

The release source carries its own `sections/` tree and does not depend on the
mutable working sections.
